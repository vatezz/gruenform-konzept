# GRÜNFORM – Konzeptwebsite

Fiktives Portfolio-Projekt für WEBKANT. GRÜNFORM stellt kein reales Unternehmen dar; das Formular ist eine reine Demo und überträgt keine Daten.

## Technik

Statisches HTML, CSS und Vanilla JavaScript. Zum lokalen Ansehen `index.html` im Browser öffnen oder einen beliebigen statischen Webserver im Verzeichnis starten.

Bildquellen und Nutzungshinweise stehen in [SOURCES.md](SOURCES.md).
